# RLC Filter Bench

Interactive simulator for a series RLC circuit (Network Theory, Module 4 – circuit analysis in the s-domain).

**Live site:** https://hillbillies1122-create.github.io/rlc-filter-bench/

- Sliders for R, L, C, input amplitude and frequency
- Band-pass (output across R) and notch (output across L + C) side by side
- Live scope view, Bode plot, harmonic table, pole-zero map and step response
- Listen to each filter's output with Web Audio

Default values: R = 22 Ω, L = 10 mH, C = 2.2 µF → f₀ = 1073 Hz, Q = 3.06.

Everything runs in the browser from the single file `index.html`.
